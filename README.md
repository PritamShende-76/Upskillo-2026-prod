# rise-together-app

# FE installation Steps

GO to FE folder and open command prompt and add following commands

1. npm i
2. npm run dev

From BE
$ alembic init alembic Not needed if alembic folder is already present
$ alembic revision --autogenerate -m "table update"
$ alembic upgrade head
